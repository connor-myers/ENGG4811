\section{Model Architecture Summary}

In Section \ref{model_architecture} a variety of machine learning architectures and techniques were discussed. In this section, it will be made explicit the exact machine-learning architectures that will be evaluated. There will be four machine learning models investigated in this thesis, with a variety of additional configurations.

\subsection{SVM with TF-IDF}

\noindent
In this model, features will be generated using tf-idf. These features will be fed into an SVM classifier.

\subsection{Pre-trained SVM-Transformer Hybrid}

\noindent
In this model, features will be extracted using CodeBERT or UniXcoder (both configurations will be tested) in their base pre-trained form (\emph{no} additional fine-tuning). Sentence embeddings will be pooled from the contextualised token embeddings, with both mean and CLS pooling strategies investigated. Classification will be done on these sentence embeddings using an SVM.

\subsection{Fine-tuned SVM-Transformer Hybrid}

\noindent
This model is the same as above, except the fine-tuned encoders generated from the model described in Section \ref{fine-tuned-encoder} will be used.

\subsection{Fine-tuned Transformer with neural-network classifier}
\label{fine-tuned-encoder}

\noindent
In this model, CodeBERT and UniXcoder will be attached to a neural network classifier and fine-tuned on the training dataset. In addition, experiments will be conducted using both mean and CLS pooling strategies. \\

\subsection{Training Settings}

This section details the important hyperparameters used for the machine-learning models.

\subsubsection{SVM Classifier}

\begin{itemize}
    \item \textbf{Loss function}: Hinge loss
    \item \textbf{Penalty:} L2 Regularisation
    \item \textbf{Lagrangian Multiplier:} $e^{-3}$
    \item \textbf{No. Epochs:} $5$
\end{itemize}

\subsubsection{CodeBERT and UniXcoder}

\begin{itemize}
    \item \footnote{Ideally, this would be much higher. A low batch-size for training experiments was a limitation of the VRAM of the testing machine.}\textbf{Training batch size:} $4$
    \item \textbf{Validation batch size:} $32$
    \item \textbf{Learning Rate: } $5e^{-5}$
    \item \textbf{Max gradient norm: } $1.0$
    \item \footnote{It was experimentally determined that no extra accuracy or decrease in loss was obtained for any additional iterations}\textbf{No. Epochs:} $3$
\end{itemize}

\section{Validation Performance Discussion}
\label{validation_discussion}

\noindent
Despite these results likely being inflated compared to a more realistic test dataset, the results generated on the validation dataset are interesting. \\

\noindent
The most surprising result was the performance of pre-trained CodeBERT and UniXcoder using an SVM classifier. Despite the encoders having no fine-tuning, all encoders and pooling types (aside from CodeBERT with CLS pooling) achieved accuracies close to $65\%$. \\

\noindent
More importantly, however, was that the accuracies of these hybrid models improved when using the fine-tuned encoder. For example, pre-trained CodeBERT with CLS pooling using an SVM classifier only achieved an accuracy of $47\%$. However, when using the fine-tuned CodeBERT encoder with an SVM classifier, the accuracy increased to $72\%$. This indicates that fine-tuning has had a beneficial effect. \\

\noindent
The best performing model was UniXcoder with CLS pooling using a neural network classifier, which had an accuracy of $80\%$ and a loss of $1.08$. Generally, all the results for classifiers using fine-tuned encoders were similar. There are two alternative explanations for why the linear SVM classifiers (using fine-tuned encoders) performed similarly to neural-network classifier models.\\

\noindent
Firstly, it is possible that given the dataset is so small, we should expect to see similar performance between the two. Because SVM classifiers are far simpler than neural network classifiers, they may perform better with small datasets. \\

\noindent
Secondly, the SVM classifier's results may be more inflated by the bias in the validation dataset than the neural-network classifiers due to how SVM classifiers make predictions. The latter is the more likely explanation, as the performance gap between SVM classifiers and neural-network classifiers widens on a realistic test dataset, as seen in Section \ref{experiment_results}. \\

\noindent
Finally, for our validation set we can confidently conclude that CLS pooling has performed better. While the accuracies have a statistically insignificant difference in most cases, the values of loss are drastically different. In Table \ref{tab:validation_perfomance_fine_nn} we can see that CLS pooling produces a lower loss compared to mean pooling for both UniXcoder and CodeBERT\footnote{Recall from Section \ref{loss} that a lower loss is better}.
