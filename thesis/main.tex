\noindent
Taint analysis tools scan code for vulnerable dataflows. A vulnerable dataflow is any dataflow where user-inputted data (i.e., tainted data) can reach a security-sensitive operation without first being sanitised. Taint analysis tools do not implicitly know which methods are security sensitive; they must be provided a list of relevant security-sensitive methods. Taint analysis tools typically provide a default configuration of commonly used security-sensitive methods, although these often prove insufficient in many use cases. In such cases, security analysts usually develop a configuration manually, which is time-consuming and error-prone. Automating this task would save developers time and enable taint analysis tools to operate more effectively. \\
 
\noindent
Javadoc is an informal and natural language description of code, and it may contain information relevant to security-sensitive method classification. In this thesis, we aim to extract security-relevant information from Javadoc with machine-learning techniques and use this to classify security-sensitive Java methods automatically. \\

\noindent
Our machine learning approach utilised Microsoft's pre-trained model \emph{CodeBERT}, which was fine-tuned on a dataset of security-sensitive Java methods. Our highest-performing model achieved an F1-score of $0.68$.

%Automatic classification of security-sensitive Java methods was implemented using a machine-learning approach. A variety of different machine learning implementations and configurations were evaluated, however the foremost architecture explored was extending existing relevant pre-trained models (CodeBERT and UniXcoder) by fine-tuning the models on a dataset of security-sensitive Java methods. The best performing model achieved achieved an F1-score of $0.68$.\\
